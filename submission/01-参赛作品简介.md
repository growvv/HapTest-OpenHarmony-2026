# HapTest：面向 OpenHarmony 应用的多模态智能测试与性能分析框架

**学校：北京航空航天大学　团队：SMAT　作者：刘发荣（独立作者）**

HapTest 是面向 OpenHarmony 应用的测试框架与工具链，围绕“页面如何探索、动作能否可靠执行、交互为何卡顿”组织测试能力。框架连接 HDC、uitest、Hypium RPC 和 ArkUI Inspector，以 Page/Component/PTG 建模页面与迁移，支持 DFS、BFS、随机、回放和静态引导扩展。

作品新增多模态任务规划：联合截图、控件候选、任务与历史生成 JSON 决策，限制模型从当前候选中选择动作，通过 HarmonyDevice 检查观察新鲜度，每步执行后重新观察。默认预览，显式开启执行。新增逐帧分析：采集 hitrace、调用本地 trace_streamer 转换 SQLite，读取 frame_slice，按进程、类型和时间筛选，输出逐帧 JSON、CSV、HTML 及 P50/P95。系统 flag 与耗时超预算分开呈现。

框架提供 CLI、TypeScript API、JSON-lines 会话和 Web Viewer。设备租约、动作队列、锁屏识别、选择器歧义处理与不确定动作不重放构成新会话路径的执行约束。参赛方向为开源鸿蒙框架与工具链创新。

2026年11月7日本地构建通过，23 个测试文件、68 项测试通过。新增模块已完成离线与本地协议验证；真机 trace 和在线模型效果仍需按验收方案校准，不以样本数据代替真实性能结果。
